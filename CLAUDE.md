# CZN Damage Calculator

Calculates Chaos Zero Nightmare card damage so the owner can compare builds (partners, equipment,
memory fragments, save-data setups) per character and maximize damage.

A website: React + TypeScript, mobile-first (the owner plays on phone), data saved in the browser.
The original Excel workbook generator was removed (owner, 2026-10-27); it is in git history if ever needed.

```bash
npm install
npm run dev        # local dev server (add -- --host to open it on the phone over Wi-Fi)
npm test           # Vitest: tests/ (engine, migrations, each character)
npm run check      # lint + test + build (what the deploy runs before the browser tests)
npm run test:e2e   # builds, then Playwright: the real site in a browser, Android phone + desktop (e2e/site.e2e.ts)
npm run build      # type-check + production build to dist/
npm run lint       # oxlint
npm run screenshot # phone (390px) + desktop PNGs of every tab -> screenshots/ (see scripts/screenshot.mjs:
                   # --tab Buffs, --phone, --tap "text", --save file); read them to check design changes
# Re-import every character (cards, potentials, Manifest Ego) from Prydwen (after a game update;
# review the git diff). One page per character (plus its cznmetadecks page for card art); --cache <folder> keeps
# them for re-runs; card art already in public/cards/ is kept (--refresh-art downloads it again).
# Python is not on PATH on the owner's PC; use the project venv:
.venv\Scripts\python.exe scripts/import_prydwen.py
```

## Code

- `src/engine/` is the math with no UI code: `types.ts` (presets, settings, save format), `buffs.ts`
  (value parsing, preset switches, class limits, buff matching), `calc.ts` (final stats, then each
  hit of each rotation play; every factor carries its sources for the formula strip).
- Characters and cards come from Prydwen (the owner trusts its "+" wording; see docs/FORMULA.md 2c):
  - `src/data/prydwen/<slug>.json`: generated by `scripts/import_prydwen.py`. Never edit by hand;
    a re-import overwrites them.
  - `src/data/characters/<slug>.ts`: our additions per character (character buffs, card buffs,
    notes, corrections such as `targetRavaged`), keyed by the import's card ids (`card-341`).
    Manifest Ego buffs are character effects with `egoLevel` (on from the build's level).
    Card fields set here override the import; notes are joined. `src/data/helpers.ts` has `cardBuff()`.
    Put character `effects` before `cards`.
    Overrides may rename a card (`name`, e.g. Flicker Blade (Amped)); `replaceNotes` drops the import's notes;
    `extraCards` adds cards Prydwen lacks; `potentials: { '3-1': { text } }` replaces a node's wording with the in-game text (`name` too if it differs).
  - `src/data/merge.ts` combines the two; `checkAdditions()` (run by the tests) catches unknown
    slugs or card ids and duplicate effect ids.
  - Deck per build (`build.deck`, `src/engine/deck.ts`): `{id, preset}` entries resolved live from the presets
    (old non-preset cards keep `{id, custom}`). The Ego skill and the cards a picked card `creates`
    (`creates: [...]` in `characters/<slug>.ts`, e.g. Rossweisse's shards) join automatically with id `auto:<presetId>`,
    and so do cards with `egoLevel` from that Manifest Ego level (Ego effects that deal damage: Narja's E6, Rossweisse's E2);
    nobody adds them by hand. A deck card's preset effects count while it's in the deck. Teammates' decks
    (`Teammate.cards`) only add buffs. Cards are picked on the Cards tab as pictures (`src/ui/CardFace.tsx`).
  - Card art (owner, 2026-10-27: copy it, best quality): the import copies every character's art into
    `public/cards/<slug>/` and sets each card's `image`. Source: cznmetadecks.com (420x632, the game's files; matched by
    card or base card name, `ART_NAMES` for names that differ), else Prydwen (200x300). Every picture on the character's
    cznmetadecks page is copied, so `extraCards` can set `image` to one (Rossweisse's base shards).
- `src/data/presets.ts` loads the above, plus partners (`src/data/partners/<slug>.ts`) and memory fragment sets
  (`src/data/fragmentSets.ts`) with their effects (entered by hand, not imported). The owner and Claude edit these files; there is no
  in-app preset editor. Effect ids must be unique per owner, because saved switches are keyed
  `"Owner|effectId"` (owner = character, partner, set or card name). Renaming an id resets that switch.
  Partner Ego skill damage is out of scope (owner, 2026-10-27: nobody uses it for damage); character
  Ego skills are cards like any other (imported from Prydwen).
- Preset effect wording (owner, 2026-10-27): `name` uses the in-game words (Prydwen's text, or the owner's
  wording for keywords, partners and sets); no `notes` on effects. When the switch depends on the fight, set
  `hint` (a few words, e.g. `'ATK > 500'`), shown as a grey chip; other explanations go in code comments.
  Buff rows show colored chips in the formula strip's colors (`src/ui/BuffChips.tsx`).
- `src/data/settings.ts`: formula constants and rules (defaults + notes); edited on the Settings tab.
- `src/store/`: `save.ts` (`SAVE_VERSION`, defaults, new objects), `migrate.ts` (older saves), `storage.ts` (localStorage
  autosave, backup export) and the React context (`store.tsx`). A stored save that can't be opened is left untouched, with autosave off,
  until the owner decides; that and failed autosaves show a warning under the header (`src/ui/SaveWarnings.tsx`). If you change the save format, bump `SAVE_VERSION` and add a step to
  `migrate()` so the owner's saved data keeps working.
- `tests/`: `engine/` (formula, buffs, cards, plays, team), `migrate.test.ts`, `save.test.ts`, `characters/<slug>.test.ts`, shared
  `helpers.ts`. `fixtures/save-v1.json` is an old save (Mei Lin with one Strike), also loaded by the browser tests and screenshots.
- `src/ui/`: tabs Setup, Buffs, Cards (library + ordered rotation), Results (color-coded formula
  strip per play, tap for hits), Settings (rules, backup). At 1000px or wider, Results sits beside
  the other tabs.
- Card text (owner, 2026-10-27): the in-game wording from the owner's screenshots goes in `text` in
  `characters/<slug>.ts`, with tokens for the active build's numbers (`src/engine/cardText.ts`): `{100%}` base %
  raised by the card's potential and Card % buffs (`shownPct` in calc.ts), `{E1:...}` / `{E3:6|4}` Manifest Ego,
  `{P3-1:...}` Potential node (switch on Setup > Potentials, `build.potentialNodes`, missing = on). A card's
  `upgrade: null` turns off its potential upgrade (Mei Lin's Jewel V). Tokens nest: `Heal {P3-1:{70%}|{100%}}`.
  A node that adds a keyword also adds the tag: `nodeTags: { '3-1': 'Blessing' }` (only while the node is on; teammates: on).
  A node that changes a card's numbers: `nodeCard: { '3-1': { pct: 0.7, hits: 2 } }` (Chizuru's Moonslash).
  `{F40%}` is a Fixed damage % (raised only with the potentialFixed setting). `{120%@id}` is another card preset's base %, raised by that
  card's buffs (the Extra Attack on Renoa's Dirge Bullet).
  The step-by-step process is the `card-review` skill (.claude/skills/card-review).
- Card upgrade potentials: build `basicLevel` / `signatureLevel`, card `upgrade`
  (Basic / Signature; `pct` is then the base %), `potentialFactor()` in calc.ts; the Manifest Ego
  levels that add +3 (E3 and/or E5; some characters have both) are parsed from the import (`potentialEgo` in merge.ts). See docs/FORMULA.md 2c.
- Team snapshot (docs/FORMULA.md 2c): each build has up to `TEAM_SIZE` teammates
  (character, Ego level, partner, 3 sets, picked cards). Effects have `target` self (default) /
  allies / enemy; teammates give only allies/enemy effects, with switches keyed
  `"Teammate>Owner|effectId"` (`teamKey`). Every switched-on buff counts on every hit (snapshot).
  My boosts/buffs have a label-only `from` field (teammate equipment).
  Team damage (owner, 2026-10-28; `src/engine/team.ts`): a slot links a saved build of that character (`Teammate.build`;
  missing = their active build, `NO_BUILD` = buffs only); `withLinkedTeam` takes the slot's Ego/partner/sets from it.
  A play with `by` (slot index) is that teammate's card, computed by `teammateView` as their own build would
  (teammate deck ids = preset ids). `computeBuild(..., saves)` gets every character's save; `byCharacter` splits the totals.
- Triggers (`triggers` on a character or card; Selena's Mark, Coordinated Attacks): a play matching `on` adds the trigger
  card's hit, computed with the owner's build (`others`: only other combatants' plays; `weakness`: Weakness Attacks only;
  `counter`: needs that per-play stack; `perStack`: one hit per stack (Renoa's Dirge Bullets discarded); `chance`: expected value; `egoLevel`). Shown under the play as `triggered`.
  `notACard` cards (effect hits) don't match card-type words (Attack / Skill / Upgrade) and set off no triggers.
- Attack list (per build, `build.rotation`): each play has optional hits, `cost` (only for `perCost` cards: "X% for
  each Cost of this card", damage = % x Cost), `vulnerable`, a count for `perCount` cards ("X% for each card in
  hand", kept in `stacks` under the card's `perCount` name, default 1; a `counter` of the same name reads that number: Tenebria's Rhythms;
  a card's `counterHits` adds hits while a counter is above 0: Yuki's Inspiration),
  `weaknessDebuff` and `stacks` per counter name; buffs with `counter` read the play's stacks
  (capped at max stacks). Buff type `Card %` raises a card's base % like a potential (only on cards
  with an upgrade: "Double all effects"); `Card +` (a Potential node's "+X%", owner 2026-10-30) adds to the base % before the upgrade
  (Shadow 110% = (80% + 15%) x 1.16); `Base %` ("+X% base Damage Amount") adds to the shown card %; `Final` ("final Damage
  Amount") is its own multiplier. Effects: `egoBelow` (off from that Ego level), `minAttack`, `attackBonus.every`
  (`thresholdStat: 'Defense'` / `'Health'` / `'Critical Chance'` / `'Extra Damage'` makes both read that stats-screen stat: Adelheid's 7, Cassius's 5-1, Renoa's 7, Selena's 5-1).
  A card's `followUp` adds Fixed damage (a share of the next matching play's damage), e.g. Rossweisse's Ego skill.
- Saves are per character: builds (partner, Manifest Ego level, card upgrade levels, 3 fragment set
  picks, stats, team, deck, attack list...), boosts and buffs.
  Preset switches that are missing count as on; own boost/buff switches that are missing count as off.
- Constants and rules belong in settings, never hard-coded in the engine.
- Document every new assumption with its source or "Unconfirmed": general rules in docs/FORMULA.md, one character's in
  docs/characters/<slug>.md.
- "Applies to" matches ALL, an exact card name, or one tag in the card's comma-separated Tags;
  also `A & B` (all), `A/B` (any), `N+ hits`, card kinds `DoT` / `Extra Attack`, `Defense-Based` (DEF cards), and the card's own
  type (Attack / Skill / Upgrade), element and cost (`1-cost`, `2+ cost`) fields; buff types
  Crit Chance / Crit DMG add to the crit stats of matching cards only.

## Formula (summary — full notes and sources in docs/FORMULA.md)

```
Final ATK  = Stats-screen Attack (includes partner base ATK + fragments; NOT partner effects or equipment)
             x (1 + partner/equipment ATK%) + equipment flat ATK
Card mult  = (Card % x MultFactor + Additive buffs incl. Morale)
             x Weakness DMG (if the card applies weakness or a Weakness Attack buff matches; base 125%)
             x (1 + Vulnerable) x (1 - Enemy DR) x (1 - Weakness debuff) x (1 + Ravaged factor if target Ravaged)
Damage     = Card mult x Stat x 0.35 x (1 + Elemental DMG%) x (1 + Extra/DoT DMG%) x Enemy DEF mult
             Stat = Final ATK, or (ATK x 0.3 + DEF x 2.1) for DEF cards; Fixed = % x Final ATK x 0.35 (Unconfirmed), no other factor
Crit       = Damage x Crit DMG (stat is the total multiplier); Expected = Damage x (1 + CritRate x (CritDMG - 1)), per hit
```
- "+X%" buff text = Additive; "X%" without "+" = Multiplicative (owner's rule).
- MultFactor = 1 + sum (Summed, default) or product of (1 + each) (Chained) — Settings tab.
- Morale = +20%/stack additive, max 20 stacks.
- Vulnerable / Weakness debuff are switched on per play; first-hit-only buffs apply to hit 1 of each play.
- Partner class-limited effects only apply when the partner's class = the character's class.

## Screenshot collection

`card-screenshots/<slug>/` (the owner's PC only, git-ignored) holds in-game screenshots from the owner's own account, for every character
with a `src/data/characters/<slug>.ts`; other characters' folders are empty. Look here before asking the owner for a level, a stat or a card's
wording, and read only the files you need. File names are listed in the `card-review` skill, section 1.
- **Levels**: any `node-*.png` shows the whole Potential tree (`potential.png` too, where it exists). Badges are level / max, Ego bonus included; `potentials` in
  `src/data/prydwen/<slug>.json` says what each node is. A node without a badge is unlocked when dark, locked when bright yellow.
- **Ego level**: any `ego-<N>.png` shows all six levels: unlocked in color, locked grey with a padlock. Not every character has one; then use the skill's section 3.
  The "00" badge on the stats screen isn't the Ego level (Cassius is E6 and shows it too).
- **Stats**: `stats-detail.png` has the real Attack, Critical, Weakness, Extra and Damage over time numbers to check calculations against.
- **Wording and card %s**: `card-*`, `epiphany-*`, `related-*`, `ego-skill*`, `ego-<N>` and `node-*`; the %s are at the owner's levels, so dividing by the upgrade factor gives the base.
- **Snapshot**: they show the account when they were taken (see the file dates), so ask for new ones if the owner has levelled the character since.
