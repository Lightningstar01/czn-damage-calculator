# Amir

What the owner confirmed about this character's cards. The general rules are in [FORMULA.md](../FORMULA.md).

- **Amir** (owner's screenshots, 2026-11-01; game version 841, taken from the same day's Rin review, not shown in these screenshots; level 20, E6, Basic 0 + 6,
  Common 0 + 6, Signature 0 + 6, nodes 3-1, 5-1 and 7 locked; Attack 207, Defense 94): every in-game % is Prydwen x 1.12.
  - **Prydwen corrections**: "Metalize" is Metallization; Full Metal Hurricane V has 3 hits (Prydwen's number: 1); Metal Pierce IV's Cost cut is
    "On Recover ... for 1 turn until activated"; "Defense above 250 / 300" is "250 / 300 or higher".
  - **Metallization** (User, 2026-11-01): one play per strike, always in the deck (it comes with the Ego skill). 80% Defense-Based, normal Order damage:
    Attack Card buffs don't reach it and the Extra Damage stat doesn't boost it. Card upgrades don't raise it (it still shows 80% at level 6). The owner counts the strikes,
    so no rule here decides what sets one off (see the in-game test below).
  - **Full Metal Hurricane's bonuses** (User, 2026-11-01): +20% (base and IV), +60% (I), +50% (II) reach Metallization strikes only, not the card's own hit. They and
    Metal Extraction V's +30% are additive switches on each strike's play. II's "add 1 Hit": each strike hits twice, both with the +50%. With II on, leave the strike's Hits unset
    (one play per strike), because the added hit goes after whatever Hits says.
  - **Full Metal Hurricane III** (User, 2026-11-01): 224% once when played. The end-of-turn 120% is its own play, one per turn, with Hits set to the Metallization decreased (up to 2).
    Upgrades don't raise it: it still shows 120% at level 6.
  - **Metal Pierce I**: a per-play switch, In Metallization state, adds the hit. New plays start with it on (Claude's choice, as with Rin's stance; the owner can change it). **Metal Pierce II**: Metallization
    decreased per play, +150% each, additive and unraised (it still shows +150% at level 6). **Full Metal Hurricane V**: set Hits on the play (3 + Metallization decreased, up to 2).
  - Vulnerable is set per play, including the Vulnerable Metal Pierce inflicts. All-enemy damage counts one target. Counterattack (Hovering Metal II), Shields, Damage Reduction, Weaken,
    Damage Taken, Resolve and the Ego levels' Metallization gains aren't counted.
  - **Unconfirmed** (in-game test `amir-unconfirmed`): whether Steel Resolve's Shield and Metallization's own 80% Shield set off a strike; whether a strike crits; whether node 7's +10% is additive (it can't go into the
    card's % as it has no upgrade); whether 5-1's +5% is part of Rapier's shown % (`Card +`, like Selena's 5-1).
