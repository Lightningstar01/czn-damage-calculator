# Anika

What the owner confirmed about this character's cards. The general rules are in [FORMULA.md](../FORMULA.md).

- **Anika** (owner's screenshots, 2026-11-01; level 60, Attack 817, Defense 236, Health 641, Critical Chance 36.9%, Critical Damage 158.9%, Extra Damage 15.3%, E2; Basic and Common upgrades 1/10, Signature 7/10; 3-1 and 7 unlocked, 5-1 and 5-2 locked):
  every in-game % is Prydwen's base x 1.02 (Basic) or x 1.14 (Signature), except where listed below. `gameVersion` 841 is taken from the other reviews the same day: the screenshots don't show it.
  - Prydwen corrections: Shock Gun IV is a Skill (Prydwen Attack). Rampage Trigger hits 4 times (the import read "* 4" as 1 hit). Warming Up III draws a Lead card, not a Lead Attack Card. Warming Up IV's buff is on Attack Cards "of this unit". Ego levels and nodes: Prydwen's wording matches the game.
  - **Shockwave** (User, 2026-11-01): the number is turns, not stacks, so Shock Gun IV's 3 Shockwave is still +50%. It's a per-play switch for +50% Damage Amount taken, additive (FORMULA.md, Teams), on a Ravaged target, on every ally's hits, the hit that applies it included. Shockwave's 2x Tenacity Damage isn't counted.
  - **Stampede** (User, 2026-11-01): each stack gives Anika +10% and allies +5%, on Attack Cards, max 5 stacks. "2x" replaces the amount for her. Stampede is set on each play, from what the fight gave the turn before (Next Turn Stampede) and from E6. A Coordinated Attack and the Ego skill aren't Attack Cards, so it skips them.
  - **Ignition Slash V** (User, 2026-11-01): anyone's Basic Attack sets off the 100% Coordinated Attack, computed with Anika's build. It stays 100% at Signature level 7, so no upgrade, and it's an Extra Attack as the owner ruled for Selena's (2026-10-28).
  - **Destroy** on Rampage Trigger: +100% additive on each of the 4 hits while Target Ravaged is on, following the game's keyword text and the snapshot rule. How the +100% works across the 4 hits in game: **Unconfirmed**; in-game test `anika-readings`.
  - Node 3-1 adds the Lead tag to Blaster Swing and Hold Position while it's on (the game's node text calls it Position Hold).
  - Node 5-1 (+5%, +10% more from Attack 250) is read as part of Blaster Swing's shown % (`Card +`), like the other characters' 5-1. **Unconfirmed**, locked for the owner; in-game test `anika-readings`.
  - Node 7's +10% Attack is on the stats screen, so nothing is added on top, like Owen's 7 (User, 2026-11-01). It's reference text.
  - E4's "+50% Damage Amount" on Buffalo Dive is additive, with 300% on the card, the same as Selena's E4 with this wording. **Unconfirmed**, locked for the owner; in-game test `anika-readings`.
  - Warming Up II's 50% is multiplicative, and Efficiency's 2x is 2 stacks (100%). It reaches base 2-Cost or higher Attack Cards, which is the import's cost, so a Cost decrease doesn't change it. Warming Up IV's 25% x Attack Cards in hand is set on each play. Whether the game counts the hand when Warming Up IV is activated or as it changes: **Unconfirmed**; in-game test `anika-readings`.
  - Ignition Slash III's count of Lead cards in All Piles is set on the play.
  - Not counted: Tenacity Damage, AP, draws, cost changes, Lead's 50% cost chance, whether Efficiency's condition is met, other enemies (all-enemy damage counts one target).
