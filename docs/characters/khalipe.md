# Khalipe

What the owner confirmed about this character's cards. The general rules are in [FORMULA.md](../FORMULA.md).

- **Khalipe** (owner's screenshots, 2026-11-01; level 60, Attack 436, Defense 215, Health 490, E0; Basic Card Upgrade 1/10, Common 1/10, Signature 5/10; 3-1 and 7 on, 5-1 locked):
  every in-game % is Prydwen's base x 1.02 (Basic) or x 1.10 (Signature), except where listed below. Instinct, as on Prydwen: the stats screen's icon matches Nia's, and its Order Damage 3.3% is a stat bonus, not the character's element.
  - Prydwen corrections: E4's Deploy Veil is +30% (Prydwen +10%). E6's Silver Veil bonus is +150% (Prydwen +100%). E5 names Signature (Prydwen Unique). Rally V has 150% Shield (Prydwen lacks it). Nodes 5-1 and 7 are "or higher" (Prydwen "greater than"). Prydwen's own wording otherwise matches, rephrased.
  - **Upward Slash** (from the numbers): node 3-1's -40% comes off the base %. 184% at Basic level 1 = (220% - 40%) x 1.02; 220% x 0.6 would show 135%. All-enemy damage counts one target, so with one target the node only lowers damage.
  - **Vulture Ejection** (from the numbers): node 7's +10% is part of the shown % for Damage and Shield. 143% = (120% + 10%) x 1.10, 121% Shield = (100% + 10%) x 1.10, and every epiphany agrees (`Card +`). Epiphany V's 40% Shield isn't raised.
  - The Attack 700 bonus (+20% Damage) is taken the same way. **Unconfirmed**, the owner's Attack is below 700; in-game test `khalipe-readings`. Display limit: from Attack 700 the card's Shield line also shows that +20%, and it never shows the Defense 300 bonus. No damage depends on it, as Shield isn't computed.
  - **Celestial** (User, 2026-11-01): each proc of Vulture Ejection is one more play on the attack list, with full damage and buffs. Nothing triggers it automatically.
  - **Silver Veil** (User, 2026-11-01): each activation at 3 stacks is a play of the Silver Veil card, always in the deck: the Ego skill brings the plain Vulture Ejection, and that brings Silver Veil. It deals 500% Defense-based and isn't raised by card upgrades (the keyword shows 500% at Signature level 5). It isn't a card, so Attack Card buffs skip it. Whether it crits and counts as Extra Damage: **Unconfirmed**, assumed crit yes, Extra Damage no; in-game test `khalipe-readings`.
  - **Greatsword Aquila II** (User, 2026-11-01): "When activated, +40% Damage Amount" counts on every play of that card. The owner isn't sure of this reading. **Unconfirmed**; in-game test `khalipe-readings`.
  - **Deploy Veil** (User, 2026-11-01): E4's +30% per stack (max 2) is additive, set per play, and reaches all Khalipe's damage including Silver Veil's hit. Allies don't get it.
  - Greatsword Aquila, I and V: "Vulture Ejection in hand" is switched on per play for the +120% / +170%. The +1 Cost isn't counted, so buffs that read Cost ("2+ cost") see the card as 1-cost. With it, the play would also set off Celestial: add that proc as a play.
  - Greatsword Aquila IV: "Greatsword Aquila IV Retained" is set on the Vulture Ejection play. Stacks add up with no limit; whether several Retains stack: **Unconfirmed**; in-game test `khalipe-readings`.
  - Ego skill: "Create 1 Vulture Ejection" adds the plain card to the deck, whichever epiphany the deck holds. **Unconfirmed**; in-game test `khalipe-readings`. E3's 350% is additive and written as Selena's E4: locked on the owner's account, no preview taken.
  - Node 5-1's +5% is part of the shown % (`Card +`), like node 7. **Unconfirmed**, locked; in-game test `khalipe-readings`.
  - Not counted: Shields and Shield gain (E1, E4, node 7's Defense bonus), Tenacity, Damage Reduction, Weaken, draws, other enemies. Overpower II's Vulnerable is the per-play Vulnerable switch.
